# Mohamed Web Studio

Static responsive portfolio built with HTML, CSS and vanilla JavaScript.

## Pages
- `/` Main portfolio
- `/demos/north/` Fashion e-commerce concept (interactive product cart and WhatsApp demo order)
- `/demos/ember/` Restaurant concept (menu selection and WhatsApp inquiry)
- `/demos/forge/` Fitness concept (program/package inquiry and WhatsApp)

## Features
- Responsive Arabic-first layout.
- Services and price tiers with EGP, SAR, AED currency selector.
- Every pricing CTA opens WhatsApp directly with the selected package in the message.
- Working mobile navigation and interactive concept demonstrations.
- The concept pages are illustrative demos, not production commerce or booking systems.

## Deploy
Import this repository into Vercel and set the project root to the repository root. No build command is required; output is the repository root.
